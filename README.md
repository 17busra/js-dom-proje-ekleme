# JavaScript ile Dinamik Tablo Yönetimi 📋

Bu proje, JavaScript kullanılarak HTML DOM (Document Object Model) manipülasyonunun nasıl yapılacağını gösteren temel bir form uygulamasıdır. 

**Projenin İşlevleri:**
* Kullanıcıdan Yazar (Author), Proje (Project) ve Maliyet (Cost) bilgilerini alır.
* Basit form doğrulama (validation) yaparak boş alan bırakılmasını engeller.
* Girilen verilerle sanal HTML elementleri (`tr`, `td`) oluşturup bu verileri mevcut tabloya dinamik olarak ekler.
* Ekleme işlemi bittikten sonra arayüzü yeni girişe hazırlamak için form alanlarını temizler.

**Kullanılan Teknolojiler:**
* HTML
* CSS
* Vanilla JavaScript (Saf JS)
